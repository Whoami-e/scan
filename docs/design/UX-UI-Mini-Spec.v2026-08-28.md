## 1. 产品定位

### 1.1 一句话

把纸质文档快速转换为清晰、规整、可分享的 PDF。

### 1.2 目标用户

- 学生：讲义、作业、手写笔记。
- 职场用户：合同、会议资料、报销单。
- 个体经营者：票据、收据、身份证明材料。

### 1.3 MVP 目标

- 无需登录即可拍摄或导入图片。
- 自动识别文档边缘，失败时允许手动调整。
- 支持基础图像增强。
- 支持逐页确认的多页扫描。
- 支持页面删除、排序、重新编辑。
- 支持生成 A4 PDF、处理重名、预览和系统分享。
- 所有文档和 PDF 默认保存在 App 沙盒。

### 1.4 非目标

- OCR 和可搜索 PDF。
- 云同步、登录、会员和团队协作。
- 自动拍照。
- 导出质量选择。
- 首页搜索、筛选和排序切换。
- 远程埋点和远程崩溃上报。

## 2. UX 原则

1. **扫描入口明显**：用户打开 App 后能立即开始扫描。
2. **图片优先**：拍摄、裁剪和增强页面以文档图片为视觉中心。
3. **自动不阻断手动**：边缘识别失败不能阻止用户继续。
4. **每一步可回退**：拍摄、裁剪、增强和多页管理之间可以返回。
5. **结果可继续编辑**：导出 PDF 不删除扫描工程。
6. **本地优先**：不要求账号，不上传文档内容。
7. **反馈明确**：拍照、处理、删除、导出和分享都必须有状态反馈。

## 3. 产品流程

### 3.1 主流程

```text
首页
  -> 拍摄 / 相册导入
  -> 边缘检测
  -> 裁剪确认
  -> 图像增强
  -> 加入当前文档
  -> 继续扫描 或 多页管理
  -> PDF 导出
  -> 打开预览 / 系统分享
```

### 3.2 页面职责

| 页面 | 职责 | 主操作 |
|---|---|---|
| 首页 | 展示本地扫描工程 | 扫描 |
| 拍摄 | 获取相机照片或相册图片 | 拍照 |
| 裁剪 | 确认或修正文档边界 | 确认裁剪 |
| 增强 | 选择扫描效果 | 加入文档 |
| 多页 | 管理当前文档页面 | 导出 PDF |
| 导出 | 配置文件名并生成 PDF | 导出 PDF |
| 设置 | 本地保存说明和日志入口 | 导出日志 |

### 3.3 导航规则

- 原型顶部的“首页 / 拍摄 / 裁剪 / 增强 / 多页 / 导出”是**评审导航**，不进入真实手机 App。
- 真实 App 使用导航栈承载流程。
- 拍摄、裁剪、增强属于连续编辑流程，返回时应保留当前临时数据。
- 多页管理和导出属于当前文档上下文。
- 设置从首页进入，完成后返回首页。

## 4. 页面 UX 规格

### 4.1 首页

**目的**

展示本地扫描工程，并提供新建扫描入口。

**内容**

- 页面标题：“文档”。
- 最近更新时间倒序的文档列表。
- 文档封面缩略图、标题、页数、更新时间、状态。
- 空状态和“扫描”主按钮。
- 设置入口。

**状态**

- 首次使用：空状态 + 扫描入口。
- 有草稿：显示“草稿”状态。
- 已导出：显示“已导出”状态。
- 加载失败：说明本地文档无法读取，并提供重试。
- 文档资源缺失：保留文档条目，提示资源不可用，不直接崩溃。

**操作**

- 点击扫描：进入拍摄页。
- 点击文档：进入多页管理。
- 重命名：通过文档操作菜单进入。
- 删除：二次确认后删除工程及关联文件。
- 设置：进入设置页。

**原型差异**

- 原型的 `screenInfo.home` 声明支持重命名和删除，但当前文档卡片只实现点击进入多页页。开发时需要补齐操作菜单。

### 4.2 拍摄页

**目的**

获取一张或多张待处理图片。

**布局**

- 深色全屏相机预览。
- 顶部：返回、页面标题、闪光灯。
- 预览区：实时文档边缘提示。
- 底部：相册、居中拍照按钮、权限状态入口。

**操作**

- 拍照：保存原图，进入裁剪页。
- 相册：支持多选，按选择顺序逐页处理。
- 闪光灯：开关切换。
- 权限被拒绝：展示说明和系统设置入口。
- 中断恢复：发现未确认临时照片时展示恢复提示。

**状态**

- 请求权限中。
- 相机可用。
- 未检测到文档。
- 已检测到文档边缘。
- 光线不足或画面抖动。
- 相机启动失败。
- 权限被拒绝。
- 发现未确认照片。

**规则**

- MVP 不自动拍照，必须由用户点击拍照。
- 自动检测只做辅助提示，不替用户确认。
- 原图保存后才能进入后续处理。

### 4.3 裁剪确认页

**目的**

确认自动检测出的四角，必要时手动修正。

**布局**

- 深色背景。
- 顶部：返回拍摄、标题、重新检测。
- 中部：文档图片和四角控制点。
- 底部：重拍、确认裁剪。

**交互**

- 四角控制点支持拖动。
- 控制点视觉尺寸可小于触控热区，触控热区不小于 44x44px。
- 重新检测只重置角点，不丢失当前原图。
- 自动识别失败时直接允许手动框选。
- 确认后调用透视矫正。

**数据**

- 原图路径。
- 图片原始宽高。
- 四角坐标。
- 当前旋转角度。

### 4.4 图像增强页

**目的**

预览并选择当前页面的图像处理模式。

**模式**

- 原图 `original`
- 增强 `enhanced`
- 灰度 `gray`
- 黑白 `bw`

**布局**

- 深色背景。
- 顶部：返回裁剪、标题、旋转。
- 中部：大图预览。
- 底部：滤镜选项和操作按钮。

**操作**

- 切换滤镜：即时更新预览。
- 旋转：切换 90 度方向。
- 重新裁剪：返回裁剪页，基于原图重新处理。
- 加入文档：保存当前页处理参数并进入多页管理。

**规则**

- 重新编辑必须基于原图重新生成，不能对处理图重复叠加处理。
- 旋转和 PDF 页面方向是两个概念：旋转记录在页面数据，PDF 方向由导出策略计算。

### 4.5 多页管理页

**目的**

管理当前文档中的页面和顺序。

**内容**

- 文档标题和页数。
- 页面缩略图网格。
- 每页页码、名称或增强模式。
- 继续扫描入口。
- 相册导入入口。
- 导出 PDF 入口。

**操作**

- 点击页面：重新进入增强或编辑流程。
- 删除页面：二次确认，不提供撤销。
- 调整顺序：支持拖拽排序。
- 继续扫描：回到拍摄页，并保留当前文档。
- 相册导入：追加图片，逐页确认。

**待确认**

- 最终排序交互采用“长按拖拽”为主，还是同时保留“上移 / 下移”按钮。
- 当前原型只有“上移”和拖拽，没有“下移”；正式实现应至少保证任意页面可以向前或向后移动。

### 4.6 PDF 导出页

**目的**

配置并生成 PDF。

**内容**

- 文件名输入框。
- 页面方向：自动、竖版、横版。
- 页数。
- 保存位置说明。
- 预计体积或处理状态。
- 导出进度。

**操作**

- 文件名为空：禁止导出并聚焦输入框。
- 文件名重名：选择覆盖或另存一份。
- 导出成功：显示打开预览和分享。
- 导出失败：保留原扫描工程和上一次成功 PDF，提供重试。

**输出规则**

- 默认 A4。
- 每页保留 10mm 白边。
- 页面按扫描图片方向自动选择竖版或横版。
- 无法判断方向时使用用户选择。
- 图片等比缩放，不拉伸。
- PDF 默认保存在 App 沙盒。

**原型差异**

- 当前原型有“打开预览”，但“分享”尚未形成独立按钮。正式实现必须补充系统分享入口。

### 4.7 设置页

**目的**

提供本地保存、卸载提醒、日志导出和版本信息。

**内容**

- 本地保存说明。
- 卸载后沙盒数据删除提醒。
- 本地日志导出。
- 版本号。

**规则**

- 不出现登录、云同步、会员或主题配置。
- 日志不得包含文档标题、文件名、完整路径、图片内容或 PDF 内容。
- 导出日志是用户主动行为。

## 5. UI 基础规范

### 5.1 视觉方向

本 Mini Spec 已确认采用当前 Energetic 原型作为 UI 基线：

- 暖黄色画布。
- 橙色主操作。
- 深紫色文字和边界。
- 直观、偏几何的卡片和按钮。
- 相机、裁剪、增强页面使用深色沉浸式工作区。

**视觉决策：** 放弃上一版 PRD 中的 Apple 风格白灰蓝色方案，正式采用 Energetic 方案。上一版 PRD 作为历史需求保留；本 Mini Spec 和后续 `PRD.v2026-08-28.md` 对视觉相关内容具有更高的当前执行优先级。

### 5.5 组件状态

#### Primary Button

- 默认：橙色背景、白色文字、轻微深色偏移阴影。
- 按下：向右下位移 1-2px，阴影减弱。
- 禁用：降低透明度，保持文字可读。
- 聚焦：橙色外环或明显边框。
- 文案：使用“扫描”“确认裁剪”“加入文档”“导出 PDF”等动词。

#### Secondary Button

- 默认：白色或暖黄色背景、深色边框。
- 按下：轻微变暗或位移。
- 禁用：降低对比度。
- 不用于页面最主要动作。

#### Icon Button

- 触控区域不小于 44x44px。
- 必须有无障碍 label。
- 返回、相册、闪光灯、旋转、重新检测、设置等使用熟悉图标。
- 不用文字胶囊替代明确的系统图标操作。

#### Card

- 用于文档条目、页面缩略图和明确的信息容器。
- 不在卡片内部嵌套另一个大卡片。
- 卡片尺寸稳定，缩略图比例固定。
- 页面卡片的删除和排序操作应使用独立可访问控件，不要依赖嵌套在 `button` 内的伪按钮。

#### Dialog / Bottom Sheet

- 用于删除确认、PDF 重名、权限说明和不可逆操作。
- 主操作放右侧或底部操作区，危险操作使用红色。
- 点击遮罩可关闭时，只适用于非破坏性提示；破坏性确认不应误触关闭。

#### Toast / Snackbar

- 用于短暂成功或状态反馈。
- 不承载必须阅读的错误说明。
- 导出失败、权限拒绝和空间不足需要可读的持久错误状态。

#### Progress

- PDF 生成期间显示进度或明确 loading。
- 进度变化不能导致布局跳动。
- 完成后切换为成功状态，并提供下一步操作。

## 6. 页面状态矩阵

| 页面 | 默认 | 加载 | 成功 | 错误 / 空状态 |
|---|---|---|---|---|
| 首页 | 文档列表 | 读取本地工程 | 新工程出现在列表顶部 | 首次使用空状态、资源缺失 |
| 拍摄 | 相机预览 | 请求权限 / 启动相机 | 已捕获照片 | 权限拒绝、相机启动失败 |
| 裁剪 | 自动角点 | 边缘检测 | 生成矫正图 | 检测失败则手动框选 |
| 增强 | 增强模式预览 | 处理图片 | 页面加入文档 | 处理失败、图片过大 |
| 多页 | 缩略图网格 | 读取页面 | 顺序或页数更新 | 无页面时禁止导出 |
| 导出 | 文件名和选项 | PDF 生成进度 | 可预览、可分享 | 文件名为空、重名、空间不足、生成失败 |
| 设置 | 说明列表 | 导出日志 | 日志准备完成 | 日志写入失败不阻断主流程 |

### 7.3 文件保留

- 已确认加入文档的页面必须保留。
- 原图必须保留，用于重新裁剪和重新增强。
- 处理图和缩略图可重建，但不能影响用户继续编辑。
- 导出 PDF 不删除扫描工程。
- 删除文档时同时清理原图、处理图、缩略图和 PDF。
- 未确认临时照片用于中断恢复，用户放弃后清理。

## 8. RN 实现边界

### 8.1 RN / UI 框架负责

- 导航栈和页面状态。
- 文档列表、设置、导出表单。
- Button、IconButton、Input、Dialog、Snackbar、Progress、Switch。
- 空状态、错误提示和页面过渡。
- 文档与页面数据的状态管理。

### 8.2 自定义组件负责

- `ScannerCameraView`：相机预览、边缘提示和底部相机控制。
- `CropEditor`：图片显示、四角拖拽和边界绘制。
- `EnhancePreview`：处理图预览和滤镜切换。
- `PageReorderGrid`：缩略图网格、拖拽排序和稳定页码。
- `PdfExportStatus`：导出进度、成功和失败状态。

### 8.3 原生模块负责

- `detectDocumentEdges(imagePath)`
- `cropAndWarp(imagePath, corners)`
- `enhanceImage(imagePath, mode)`
- `createPdf(pageImagePaths, outputName, options)`
- `shareFile(filePath)`
- `openFile(filePath)`
- `exportLogs()`

### 8.4 推荐组件策略

- 基础 UI 使用 `React Native Paper`，通过主题和样式覆盖当前 Energetic 视觉。
- 不让 UI 框架接管相机预览、透视裁剪或页面拖拽。
- 四角拖拽和页面排序使用原生手势能力实现。
- 主题颜色集中维护，禁止在页面中散落硬编码颜色。

## 9. 动效和反馈

- 页面切换：简洁的 push / fade，不使用夸张弹跳。
- 拍照后：显示短暂处理中状态，再进入裁剪。
- 滤镜切换：100-200ms 淡入淡出。
- 四角拖拽：控制点跟手，不添加延迟或弹性回弹。
- 删除：确认后立即更新列表，并给出结果反馈。
- 导出：显示进度，完成后显示预览和分享。
- 支持减少动效设置，关闭非必要动画。

## 10. 可访问性和可用性

- 所有点击区域建议不小于 44x44px。
- 所有图标按钮提供语义化 label。
- 重要状态不能只用颜色表示，要同时有文字、图标或形态变化。
- 文字支持系统字体放大。
- 深色相机页保证文字、图标、边缘线和控制点清楚可见。
- 触控拖拽时避免父级滚动抢占手势。
- 错误提示说明原因和下一步动作。
